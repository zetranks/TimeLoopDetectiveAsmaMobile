# Reborn: Eternal Loop — current systems

This is an original fantasy game project. It does not contain licensed franchise characters or assets.

## Systems added in this milestone
- Player profile data and local JSON persistence via PlayerPrefs.
- Data-driven ability definitions with cooldown tracking.
- Quest definitions, objective progress, completion events, and claim-once reward logic.
- Offline kingdom building upgrades with escalating coin costs.

## Integration status
These systems are reusable Unity components and data models. They are not yet wired into a complete game UI or a full campaign. They are local prototype systems only; a production multiplayer game must validate progression and rewards on a trusted server.

## Remaining major work
Character and environment art, animation, sound, story chapters, enemy AI, equipment and inventory UI, kingdom scenes, touch-friendly menus, account/cloud save, matchmaking, online combat, chat/moderation, device testing, and release packaging remain unfinished.
